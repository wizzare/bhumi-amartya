# Innerwork Profile Alignment

Audit date: 19 June 2026

## Pattern-to-practice test

| User pattern | Expected | Current evidence |
|---|---|---|
| Over-responsibility | Boundary or permission-to-rest practice | Some old Life Path templates contain boundary exercises, but no active issue-to-practice mapping exists. |
| Relationship wound | Safe connection or self-connection practice | Healing recommendations can use journal emotion, but the Innerwork hub does not select its module from the current wound. |
| Perfectionism | Self-compassion or “good enough” practice | No explicit active mapping found in the current recommendation runtime. |
| Overthinking | Grounding, body, or short attention practice | Static options exist; selection is not guaranteed by the user's current issue. |

Profile information is abundant in AI prompts and legacy generators. That establishes data availability, not alignment. The dormant runtime adapter maps technical profile values directly to exercises, while the active fallback ignores all profile inputs.

Consequently, a suitable exercise may appear by coincidence or AI generation, but there is no inspectable rule ensuring that today's live pattern selects the corresponding practice.

## Verdict

**PARTIAL at content coverage; FAIL at active alignment**

# Innerwork 7-Day Audit

Controlled seven-day simulation for all five users produces stored daily records and issue-specific practices.

| Capability | Reality |
|---|---|
| Repeating issue | Detectable in stored records, but no runtime frequency calculation |
| Improving issue | `practiceHelped` is stored, but no trend calculation |
| Worsening issue | Heavier reflection is stored, but no worsening classifier |
| Skipped issue | Detected; next practice becomes 2-minute Recovery |
| Anti-repetition | Only three most recent completed practice IDs are excluded |

## Five-user result

All five can receive varied doorways across seven days when navigator/date rotation changes. However, issues with one variant per navigator can cycle predictably and may repeat after the three-record anti-repeat window.

## Verdict

**7-day storage continuity works; 7-day intelligence does not.**

# INNERWORK ZONE B: GUIDED LEARNING LIBRARY

## Mission
Transform the static library into a **Guided Learning Library**. In Zone B, Bhumi acts as a teacher, ensuring the user understands "What", "Why", and "How" for every practice.

## Core Principle
Bhumi doesn't just recommend; Bhumi teaches. Every item in the library provides context and instructions to eliminate confusion and build user autonomy.

## Structure of Knowledge
For every learning item (excluding Audio Healing), the following structure is mandatory:
1.  **Apa Itu:** Definisi sederhana dalam bahasa manusia.
2.  **Manfaat:** Dampak nyata bagi kesejahteraan.
3.  **Cocok Untuk:** Masalah spesifik (Dominant Issue) yang terbantu.
4.  **Cara Melakukan:** Panduan langkah-demi-langkah.
5.  **Durasi & Tingkat Kesulitan:** Ekspektasi waktu dan energi.
6.  **Eksplorasi Eksternal:** Kata kunci pencarian Video (YouTube) dan Gambar (Google).

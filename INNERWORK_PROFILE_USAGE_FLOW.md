Blueprint  
→ Canonical Translator  
→ Human Meaning  
→ five narrative strings

→ issue key.

## Effect boundaries

- Issue selection: yes, but only through generated Human Meaning keywords.
- Practice selection: indirect only through the selected issue fallback. Stored recommendations can override it.
- Companion narrative: selects a static narrative; it does not compose live prose from each system.

There is no visible attribution explaining which profile system caused a match.

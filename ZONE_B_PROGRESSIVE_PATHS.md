# Zone B Progressive Paths

Each target issue has five stages.

## Over Responsibility

1. Body Awareness
2. Melepas Beban
3. Batas dengan Tanggung Jawab
4. Menerima Dukungan
5. Identitas di Luar Peran Penyelamat

## Difficulty Resting

1. Body Awareness
2. Izin untuk Beristirahat
3. Batas dengan Produktivitas
4. Menerima Dukungan
5. Identitas di Luar Pencapaian

## Love Block

1. Rasa Aman di Tubuh
2. Mengenali Kebutuhan Hati
3. Batas dalam Kedekatan
4. Menerima Cinta
5. Identitas yang Tetap Utuh dalam Relasi

## Inner Child

1. Rasa Aman
2. Mendengar Diri Kecil
3. Perlindungan dan Batas
4. Menerima Dukungan
5. Menjadi Pendamping bagi Diri Sendiri

## Money Block

1. Rasa Aman di Tubuh
2. Memisahkan Fakta dan Ketakutan
3. Batas dengan Kelangkaan
4. Menerima Sumber Daya
5. Nilai Diri di Luar Angka

Stage selection uses same-issue completion count, helpful/heavy ratio, and Journey learning signals.

# Innerwork Memory Audit

After 30 days Bhumi stores:

- what was recommended
- what was completed/skipped
- what result was selected
- whether the practice helped
- daily issue/context snapshots

Bhumi does not yet compute:

- what the user is learning
- how the issue is changing
- which doorway works best for this person
- recurring context before improvement or decline
- a longitudinal growth narrative

## Answer

Bhumi remembers more than clicks, because it stores the day's theme and context. But runtime recommendations primarily consume practice IDs, skip state, and individual reflection results.

**It remembers events better than learning.**

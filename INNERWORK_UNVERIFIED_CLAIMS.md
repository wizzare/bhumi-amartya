# Innerwork Unverified Claims

The following claim types cannot currently be proven and must not be presented as verified:

- “Innerwork runtime is active” beyond the narrow fact that the root server returned HTTP 200.
- “Focus Generator works.”
- “Practice Generator works” or always returns a recommendation.
- “The selected practice solves today’s dominant issue.”
- “Recovery, Reflection, and Growth are visibly distinct.”
- “Start Practice works.”
- “Completion works.”
- “Reflection saves successfully.”
- “Journey saves or updates successfully.”
- “The database contains issue, practice, duration, completion, reflection, and timestamp.”
- “The full Open → Practice → Reflection → Save → Journey flow works.”
- “There are no dead ends, blank states, missing buttons, or dead buttons.”
- “Zone B guides are complete and usable.”
- “Audio links to Bhumi” or plays successfully.
- “Innerwork evolves across Day 1, 7, 14, and 30.”
- “Actual generated content is personal, human, specific, or actionable at any stated score.”
- “Companion score 5/5,” or any other UX/content score based on simulated output, source inspection, or prior reports.
- “Ready for users,” “production ready,” “release ready,” “end-to-end validated,” “reality checked,” or equivalent.
- Any screenshot-based visual claim using earlier images that were not captured in this audit.
- Any claim derived only from filenames such as `*_VALIDATION`, `*_REALITY`, `*_READY`, `*_SCORE`, `*_TEST`, or `*_AUDIT`.

## Claims that may be made precisely

- Relevant source routes, controls, datasets, and repository calls exist.
- The root development server returned HTTP 200 at the recorded time.
- Current UI behavior and release readiness remain unknown.

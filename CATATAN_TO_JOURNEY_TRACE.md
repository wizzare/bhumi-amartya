# Catatan to Journey Trace

When Daily Guidance/Catatan becomes available, Dashboard writes:

- explicit dominant issue when present
- issue category
- Catatan summary
- main direction
- active challenge
- active opportunity
- astro summary and active events
- profile Human Meaning signals
- source confidence

This occurs independently of Innerwork button clicks. Therefore Journey remembers what the day was about even when the user does not practice.

## Final Verdict

**Journey is now a daily memory system, not only an activity checklist.**

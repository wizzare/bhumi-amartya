# Innerwork Focus Flow

## Source-to-render chain

`dailyGuidance.dailyNoteText`  
→ read from Firestore by `dailyGuidanceRepository.getDailyGuidance`  
→ page takes text before the first period  
→ appends `.`  
→ renders as `focusStatement`.

Exact page rule:

1. If `dailyNoteText` is truthy: `dailyNoteText.split('.')[0] + "."`
2. Otherwise use `currentIssue.fallbackFocus`.
3. Otherwise use hardcoded final fallback: `Amati ritmemu hari ini dengan lembut.`

## Original upstream source

When present, `dailyNoteText` was created earlier by the Daily Guidance pipeline. That pipeline may use AI output or local fallback and may incorporate blueprint, astro, wellness, and prior progress. Innerwork does not regenerate or revalidate it.

## Why “Amati ritmemu hari ini dengan lembut” appears

It is not generated by a translator or engine. It is a literal string in `app/innerwork/page.tsx`.

It can appear only when:

- no truthy `dailyGuidance.dailyNoteText` exists; and
- `currentIssue` has not produced a `fallbackFocus`.

Because every normal `issueNarrative` contains `fallbackFocus`, this exact sentence primarily indicates missing/unresolved issue state or a data-fetch failure/race rather than a personalized focus.

# Journey Read for Tomorrow

`getDailyMemory()` returns:

- yesterday/latest record
- last 7 records
- last 30 records

Innerwork consumes the 30-day records before falling back to legacy DailyState history.

Adaptation:

- completed and calmer: practice type gains positive influence
- completed and heavier: that type is reduced and the next recommendation softens
- skipped: Journey contributes no guilt; the next main practice is simplified to at most 2 minutes
- repeating issue: date rotation and recent-practice exclusion change the doorway

Catatan receives the latest completion summary through the existing Journey runtime adapter.

# Innerwork Dominant-Issue Mapping

Innerwork V5 receives exactly one normalized dominant issue from Catatan. It does not independently reinterpret the user.

## Core mapping

| Dominant issue from Catatan | Primary category | Preferred primary practices | Supporting practices | Avoid as primary |

## Selection rules

1. Match the issue to a primary category.
2. Filter by Navigator duration and current wellness capacity.
3. Prefer a practice the user has not repeated recently.
4. Choose the primary practice from current state, not profile.
5. Use profile only to refine wording or choose between equally safe candidates.
6. Use Astro only as a light contextual modifier; never change the issue.
7. A supporting practice must use a different mechanism from the primary practice.
8. Optional practices may expose broader library choices, but never compete visually with the primary practice.

## Example

```text
Catatan issue: Over-responsibility
Navigator: REFLECTION
Body capacity: medium
Recent history: boundary journal completed yesterday

Primary: Say “no” to one small, low-risk request — 5 min
Supporting: Meditasi Melepaskan Beban, shortened to 8 min
Optional: Niat Relasi Sehat — 10 min
```

The issue remains stable; only the practice mechanism progresses.

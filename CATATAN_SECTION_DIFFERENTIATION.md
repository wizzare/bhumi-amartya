# Catatan Section Differentiation

## Mental

Answers what is happening in the user’s mind using emotional capacity, nervous-system state, shadow triggers, and yesterday’s rhythm.

## Keuangan

Answers how the user is relating to resources using money block, work style, journey stability, and available energy. It does not predict money.

## Percintaan

Answers what is active in the heart using love block, relationship pattern, emotional state, and yesterday’s self-care.

## Relasi & Keluarga

Answers how the user is relating to people using relationship meaning, boundaries, recent rhythm, belonging, and support.

## Spiritual

Answers what deeper lesson is available using purpose, growth area, journey, reflection history, and one approaching-awareness context.

## Tantangan

Uses sabotage pattern, present wellness, and journey trend. It does not rely on a generic warning.

## Peluang

Uses talents, potential, current capacity, and journey momentum. It does not rely on generic positivity.

## Swap Test

Swapping Mental, Keuangan, Percintaan, Relasi, or Spiritual text would produce an obvious semantic mismatch.

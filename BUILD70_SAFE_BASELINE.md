    ```powershell
    git checkout main
    git reset --hard release/build70-production
    ```
2.  **No manual rewrites**: By using `git reset --hard release/build70-production` on `main`, we restore the entire codebase to the exact Build 70 state. Web-only files are removed, and shared configurations are naturally restored to their Build 70 app-only versions without manual changes.
3.  **Compiles and runs**: Build verification (`npm run build` and `npx cap sync android`) will be run on the clean `main` branch to guarantee production compilation safety.

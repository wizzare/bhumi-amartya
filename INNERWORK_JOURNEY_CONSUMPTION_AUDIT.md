# INNERWORK JOURNEY CONSUMPTION AUDIT

## Overview
This audit evaluates how practice recommendations are influenced by historical effectiveness and chronological growth.

## Logic Integration
- **Practice Effectiveness**: `innerworkIntelligence` now checks `practiceInsights`. If a practice has a low helpful score (Heavy), its recommendation frequency is reduced.
- **Coach Memory**: If `coachMemory` indicates a preference for short/somatic practices, these are prioritized in the `rotatedModes`.
- **Chronological Evolution**: If the `growthNarrative` shows a transition (e.g., from Responsibility to Boundaries), the practice variant shifts from "stabilizing" to "aligned action".

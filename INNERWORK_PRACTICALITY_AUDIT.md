## Load test

Workout, yoga, and healthy-food pages allow multiple selections. The practical load can therefore exceed each listed item's duration. The hub does not prescribe a maximum daily total.

RECOVERY status does not reduce the catalog or enforce the shortest option. A low-capacity user can receive or select a 20–30 minute practice, several practices, or a combined legacy task set.

## Verdict

**FAIL for adaptive practicality**

Individual exercises are often practical; the system does not match their size to current capacity.

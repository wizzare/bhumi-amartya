# Innerwork to Journey Trace

1. Innerwork reads today's Catatan, state, navigator, profile/Gaia, astro, and Journey memory.
2. Daily decision selects the issue, type, practice, duration, and intensity.
3. `updateDailyRecord()` stores `innerworkRecommendation`.
4. User may complete or leave the default skipped state untouched.
5. Completion writes the actual practice, result, response, and helped state.
6. Tomorrow reads the last 1/7/30 records and adapts duration/type/repetition.

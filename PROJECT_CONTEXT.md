# Bhumi Amartya

Bhumi Amartya is an AI-powered innerwork platform.

Purpose:
A safe digital sanctuary for people to return home to themselves through:
- journaling
- healing
- astrology
- human design
- destiny matrix
- emotional awareness
- nervous system regulation

Core Vision:
Bhumi Amartya is not a static spiritual reading app. It is a scalable, multi-user, AI-native innerwork operating system. Each user receives daily guidance based on their personal blueprint, emotional state, healing progress, journaling history, and current cosmic/astrological timing.

Tech Stack:
- Next.js
- TypeScript
- Firebase Auth
- Firestore
- Gemini AI
- Mobile-first responsive UI

Architecture Rules:
- No hardcoded users
- No single-user mock data in production flow
- All dashboard data must be dynamic
- Use repositories for Firestore access
- Use engines for business logic
- Use orchestrators to aggregate user data and generate dashboard state
- UI components should render data only
- Multilingual support: Indonesian and English
- Preserve calm, grounded, emotionally safe Bhumi visual language

Core Systems:
- Authenticated user flow
- User profile
- Blueprint engine
- Dashboard orchestrator
- Soul reflection engine
- Astro energy engine
- Journaling system
- Healing progress system
- Emotional memory system
- Audio healing page

Product Principle:
Bhumi Amartya should feel like Google Fit for innerwork: a daily companion for emotional regulation, self-awareness, spiritual reflection, and personal healing progression.

Tone:
Soft, grounded, emotionally intelligent, reflective, safe, and human.

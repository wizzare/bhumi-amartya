# Bhumi Amartya - Test Checklist

Complete this checklist on your physical Android device.

- [ ] App installs successfully
- [ ] App opens without white screen/crash
- [ ] Register works (Google Auth)
- [ ] Login works (Google Auth)
- [ ] Setup/Onboarding works (Birth data entry)
- [ ] Blueprint generated successfully
- [ ] Dashboard displays all core identity fields
- [ ] **Refleksi Jiwa** is visible and unique
- [ ] **Catatan Hari Ini** is visible and contains planetary data
- [ ] Journal saves entry successfully
- [ ] Logout works
- [ ] Login again works and data persists

# Catatan Hari Ini Role Audit

## Product Boundary

- Mirror: perenungan
- Astro: kondisi langit
- Catatan: fokus kesadaran
- Innerwork: praktik
- Journey: progres
- Wellness: kondisi diri

## Section Classification

| Section | Current role | Correct owner | Verdict |
|---|---|---|---|
| Awareness focus banner | Astro event explanation | Astro, or synthesized into Catatan | Overlaps Astro |
| Kondisi Umum | Mood/energy claim | Wellness + Catatan synthesis | Belongs only if based on actual scan |
| Mental | Mental-state interpretation | Wellness/Catatan | Valid only as part of one synthesized focus |
| Keuangan | Domain forecast/direction | Catatan at most as contextual branch | Too report-like as permanent daily section |
| Percintaan | Relationship tone | Catatan at most as contextual branch | Too report-like as permanent daily section |
| Relasi & Keluarga | Social interpretation | Catatan at most as contextual branch | Too report-like as permanent daily section |
| Spiritual | Inner silence and meaning | Mirror or Innerwork depending content | High overlap |
| Tantangan | Friction analysis | Catatan | Valid input to one main focus |
| Peluang | Potential/opening | Catatan or Journey | Valid input, not necessarily a standalone card |
| Saran Bhumi | Concrete action | Innerwork | Too actionable for Catatan |
| Mengapa ini muncul? | Astro/blueprint explanation | Astro or hidden synthesis | Should not expose source report |
| Refleksi Dirimu | Multiple questions | Mirror | Duplicates reflective role |
| Saran Bhumi block | Practical instructions | Innerwork | Role violation |

## Overlap Findings

### Mirror overlap

- Every category has `Refleksi Dirimu`.
- Spiritual content and seeded reflective questions reproduce Mirror behavior.
- Nine separate reflection areas dilute the single Mirror above it.

### Astro overlap

- AI reasons are explicitly generated from transits and natal-house activation.
- Several category prompts are organized around planets and houses.
- The global focus displays an awareness-event explanation directly.

### Innerwork overlap

- Every category ends with practical advice.
- Local enrichment adds concrete actions, breath instructions, writing prompts, time limits, and behavioral directions.
- Nine advice blocks can function as nine mini-practices.

### Journey overlap

- Local advice includes completion rate, streak, and recent practices.
- Structured Journey adapter exists but is bypassed.

### Wellness overlap

- “Kondisi Umum” and “Mental” imply current condition.
- Active UI does not reliably consume the current Daily Scan, so those claims may not be grounded in user state.

## Role Verdict

Only the concepts behind Kondisi Umum, Tantangan, and Peluang clearly belong as Catatan inputs. The current section architecture spreads Mirror, Astro, Wellness, and Innerwork roles across nine cards.

# Astro Dashboard Weight Audit

## Before

The default dashboard view included:

- Moon status
- Three narrative panels
- Awareness events
- Expansion control

This made Astro occupy substantial vertical space before the user requested detail.

## After

The default view contains one compact information block:

```text
Moon phase
Period
Next phase
Detail button
```

All interpretation and secondary systems are hidden until expansion.

## Visual Weight Assessment

| Dimension | Result |
|---|---|
| Default vertical footprint | Reduced |
| Information hierarchy | Clear |
| Primary signal | Moon phase |
| Secondary narratives | User initiated |
| Additional systems | Preserved |
| Close action placement | End of detail flow |

## Success Criteria

- Dashboard remains compact: **PASS**
- Astro remains rich: **PASS**
- User chooses depth: **PASS**

## Final Verdict

**PASS**

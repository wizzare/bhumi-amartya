# INNERWORK JOURNEY CONTINUITY

This document defines how Innerwork maintains progress and handles different user histories.

## Journey Progression Rule
If a user completed a practice yesterday, do not recommend the identical practice today. Instead, progress the practice:
*   **Yesterday:** Boundary Reflection
*   **Today:** Boundary Action
*   **Tomorrow:** Boundary Integration

## New User Protocol
If there is no historical data available:
*   **No Mentions:** Do not reference "Yesterday", "Streak", or "Progress".
*   **Focus:** Use current state (Dominant Issue + Navigator) only.

## Library Separation

### ZONE A: Recommended Today
*   **Nature:** Dynamic and Personalized.
*   **Source:** Strictly based on the **Dominant Issue** and **Navigator**.

### ZONE B: Explore Innerwork
*   **Nature:** Static Library for voluntary exploration.

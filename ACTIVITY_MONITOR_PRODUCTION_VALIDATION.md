## 5. Last Login Source
The `Last Login` value originates from the user's authentication metadata (`auth.user.metadata.lastSignInTime`) or profile (`auth.userProfile?.participationMetrics?.lastLoginAt`).
It is set exactly when the authentication event occurs and represents the start of the session.

## 6. Last Activity Source
The `Last Activity` (stored as `lastSeen` in Firestore) originates from `serverTimestamp()` generated by the Firestore backend during activity events.
It updates dynamically whenever the app is opened, a screen is changed, or the session duration increments. 
**Verification:** `Last Login` ≠ `Last Activity`. They use completely different sources. `Last Activity` updates continuously as the user interacts with the app, whereas `Last Login` is static for the duration of the session.
